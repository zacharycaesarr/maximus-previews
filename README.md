## Add a new preview

1. Create a folder under `previews/` (example: `previews/some-shop/`)
2. Put `index.html` plus any `css/`, `js/`, and `assets/` inside
3. Link it from the hub `index.html`
4. Push to `main` (GitHub Pages serves the repo root)

## Local check

Open `index.html` in a browser, or serve the folder:

```
npx serve .
```
